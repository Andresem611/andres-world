## Implementation Decisions

### Building footprints — overlaps to fix
- **Andres's House:** Shrink east boundary from x=12 to x=9. New footprint: x=6-9, y=16-22. Clears the overlap with Thoven HQ at x=10-12.
- **Chalk Lab:** Shrink east boundary from x=22 to x=21. New footprint: x=18-21, y=8-13. Clears the edge collision with the main street path at x=22.

### Building footprints — resizing for proportion
- **Thoven HQ:** Make bigger — currently 8×9 tiles (x=10-17, y=14-22). Target ~10-12 tiles wide. Exact bounds: Claude's discretion on how far east it can extend before crowding the main street or Chalk Lab. Must remain the largest building.
- **Ventanita:** Shrink to 2-3 tiles wide (currently 5 wide: x=23-27). It's a walk-up coffee window, not a full building. Stays on main street west side, south section.
- **Record Shop:** Shrink to ~3-4 tiles wide (currently 5 wide: x=29-33). Small music store.
- **Bulletin Board:** Shrink to 1-2 tiles wide (currently 3 wide: x=23-25). It's a noticeboard, not a building — functionally a sign.
- All other building footprints (Engineering Lab, GitHub Library, Starbucks, VC Office, Music Room, Idea Graveyard, Lookout Hill): keep current sizes unless a conflict arises from the above changes.

### Missing zones — all in scope for 3.3
- **Tall grass zones:** Place at 4 locations (see Hidden area access below). Tall grass tiles are collision-blocked; a narrow 1-2 tile-wide gap in the grass field is the only entry. No walkable-grass mechanic — gaps only.
- **Secret Beach:** South end of the beach strip (east side), south of the main beach area, accessed through a palm cluster gap. Hammock area. Tile on ground layer: SAND_GID. Surrounded by palms that block entry except for a narrow gap.
- **East boardwalk:** Narrow vertical path running north-south along the east side, between the sand strip and the ocean. ~x=37 or x=38 (between SAND_GID and WATER_GID zones). Connects Engineering Lab area south through GitHub Library, down to Secret Beach.
- **Welcome Sign + dock entry:** Clean path from dock north entry into main street. Add a marker tile or sign zone at approximately x=24-26, y=36 (one tile above the dock spawn area). The "Welcome to Andres World" sign text is handled by Phase 3's interaction system — 3.3 just places the walkable zone and collision-appropriate sign tile footprint.
- **Hidden NPC zone (north tip):** Small zone at the northern-most accessible area of the map, behind Lookout Hill. Accessed through a narrow gap in a tall grass row at the top. Coordinates: Claude's discretion based on map geometry.

### Path network
- **Main street spine:** Existing — x=22-28, y=0-39 (no change).
- **West cross-street:** Horizontal path at approximately y=15-16 connecting main street (x=22) westward to Thoven HQ / Andres's House area (~x=9). Gives the player a clear "turn left" moment heading to the west district.
- **East cross-street:** Horizontal path at the same y connecting main street (x=28) eastward through the sand strip to the boardwalk (~x=37). Mirrors the west side.
- **East boardwalk:** Vertical north-south path along east side (~x=37), running from the north edge down to the Secret Beach gap. PATH_GID or DOCK_GID tile (whichever looks like a boardwalk — Claude's discretion, same ✅ visual confirm workflow if a new GID is needed).
- **Idea Graveyard:** No formal path — accessed organically by walking west off main street and finding the tall grass gap. Makes it feel discovered.

## Existing Code Insights

### Reusable Assets
- `scripts/generate-map.ts`: All geometry is `fillRect()` + `placePalm()` calls. Changes are surgical — update x1/x2 params in the relevant `fillRect` calls. No architecture change.
- `tileGid(firstgid, cols, row, col)` helper: Use for TALL_GRASS_GID derivation, same as all existing GIDs.
- `buildGroundLayer()`, `buildAboveLayer()`, `buildCollisionLayer()`: Three-pass architecture. Ground = base terrain. Above = buildings + trees. Collision = blocked zones. Tall grass goes in all three (ground tile + collision block + gap carved out in collision).

### Established Patterns
- **TILE-CATALOG.md is the source of truth** — any new GID (tall grass, boardwalk if new) requires a ✅ entry before it touches generate-map.ts.
- **Tileset-preview.html hover workflow** — Claude proposes row/col, Andres hovers to confirm visual, adds ✅ to catalog. This is the mandatory gate for any unconfirmed GID.
- **Collision layer gaps**: `setTile(data, x, y, 0)` carves out walkable tiles inside an otherwise-blocked region. Already used for the dock spawn zone at y=37-39.
- **TDD pattern from Phase 3.1**: Update test assertions (overworld-map.test.ts) to reflect new building boundaries and new GIDs before changing generate-map.ts.

### Integration Points
- `generate-map.ts` → `public/assets/maps/overworld.json` (output)
- Phase 3's `src/game/config/npcs.ts`: NPC tile coordinates will need updating for any NPCs whose buildings moved (e.g., if Thoven HQ expands east, NPCs inside need new x coords).
- Phase 4+: Every interior scene references the building's entrance tile coordinates for transition detection. Phase 3.3 locks these coordinates — they're the permanent contract.

</code_context>
