# Andres World

## What This Is

A personal website built as a playable Pokemon Gen 1/2 pixel-art overworld game at andresmartinez.com. Visitors control a character and walk around "Andres World" — a Miami-themed, top-down tile-based map where every building is a project, section, or piece of Andres's life. Buildings have interiors with NPCs, signs, and interactive objects.

## Core Value

Visitors discover who Andres is by *playing* the world — every building, NPC, and hidden area reveals something real, in a format nobody else has built.

## Current State

**M001 complete.** Shipped the full site using Phaser 3 + Grid Engine + Tiled (15 slices, 131 tests, 55 requirements validated). The game is playable: 50×40 Miami-themed overworld, 14 NPCs, 4 interior scenes, 5 hidden areas, Pokemon-style title card, mobile gate, OG meta tags. Music infrastructure ready but no .mp3 files yet.

The Phaser 3 + Tiled stack made AI-assisted iteration painful — canvas text rendering, Tiled GID math, and tileset offset chains consumed the most debugging time. A stack pivot to React DOM + GridEngineHeadless was decided during M001.

**M002 planned.** Rebuild with Path A+ (React DOM + GridEngineHeadless + code-defined maps). All content carries forward: 247 lines of dialogue, 14+ NPC configs, 16 NPC sprites, player sprite, LimeZu tilesets, full design doc.

## Architecture / Key Patterns

**M001 Stack (Phaser — shipped, being replaced):**
- **Engine**: Phaser 3 + Grid Engine (scene plugin)
- **Maps**: Tiled JSON generated by TypeScript scripts (generate-map.ts etc.)
- **Tilesets**: 6 LimeZu 16×16 PNGs in GID chain
- **UI**: Phaser Container-based DialogBox
- **Build**: Vite + TypeScript
- **Deploy**: Vercel → andresmartinez.com

**M002 Stack (Path A+ — next):**
- **Rendering**: React DOM — tiles as divs with CSS `background-position`, sprites as positioned elements
- **Movement engine**: GridEngineHeadless (standalone, no Phaser) — same Grid Engine API, same movement feel
- **Maps**: TypeScript 2D arrays via `ArrayTilemap` — no Tiled, no GIDs, no tileset offset math
- **UI**: nes-ui-react (or custom DOM components) — dialog boxes, menus in React/CSS
- **Build**: Vite + TypeScript
- **Deploy**: Vercel → andresmartinez.com
- **Pixel rendering**: CSS `image-rendering: pixelated` + 4x zoom via CSS transform

**Key patterns:**
- Content/config separation: `src/content/dialogue.ts` (247 lines) holds all text, `src/game/config/npcs.ts` (175 lines) holds positions/sprites
- Programmatic map generation via TypeScript scripts — no Tiled GUI needed
- TDD RED gate: failing tests written before implementation
- Interior scenes subclass InteriorBaseScene, override `getMapKey()` and `onInteriorCreate()`
- Mobile gate: touch devices see static landing page, not broken canvas
- Deploy on push to main — no manual steps

## Constraints

- **Tech Stack (M002)**: React 19 + Vite + TypeScript + GridEngineHeadless + nes-ui-react — no game engine
- **Rendering**: DOM elements, not canvas — tiles as divs, sprites as positioned elements
- **Maps**: TypeScript 2D arrays via ArrayTilemap — no Tiled, no external map editor
- **Deployment**: Vercel, domain andresmartinez.com — static site, no SSR
- **Movement**: Tile-based grid only — no free roam, no physics
- **Art**: Pixel-perfect, Gen 1/2 Pokemon aesthetic — Miami-themed throughout
- **NPC Tone**: Self-aware, funny, fourth-wall breaking — never sincere except Keri and Hidden NPC

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Phaser 3 + Grid Engine + Tiled (M001) | Proven game engine, rich plugin ecosystem | Shipped — but AI-iteration pain led to pivot |
| Path A+ (React DOM + GridEngineHeadless) for M002 | 95% Claude autonomy, DOM rendering for trivial UI, code-defined maps | Active — M002 |
| Programmatic map generation | Reproducible, code-reviewable, no Tiled GUI needed | Active — both milestones |
| Content layer separation | dialogue.ts + npcs.ts decoupled from scene code | Active — carries forward |
| Mobile gate over D-pad | Static landing page better UX than broken canvas with D-pad | Active |
| Music infrastructure without .mp3s | Code ready, files deferred — drop in and it works | Active |
